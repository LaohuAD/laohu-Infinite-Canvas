# 导演台时间轴与工作台增量设计

## 一、设计目标

本轮在现有导演台骨架上完成可实际编排、可独立配置、可稳定保存的单轨视频生成工作台。导演台仍然只负责生成视频片段，不承担字幕、配乐、转场、多轨合成或最终成片剪辑。

本设计覆盖 `docs/导演台骨架设计.md` 中与时间轴、当前 Clip 工作区、个性化生成来源和下载入口冲突的旧条款。角色—音色绑定继续只保留为后续记录，本轮不实现。

## 二、现状与方案选择

当前项目已经具备导演台预览、项目素材库、普通 Clip、连接 Clip、提示词、动态视频参数、运行和分片文件输出。问题不在于缺少一套全新导演台，而在于时间状态、生成状态和界面状态还没有形成稳定的共享契约。

本轮采用“迁移层重构”：

- 保留现有导演台节点、视频执行链、能力档案、素材稳定 ID 和结果版本。
- 把时间位置、生成时长、滚动缩放、Clip 独立输入和个性化适配器统一进导演台状态。
- 删除新版运行链中会压紧时间线、跨 Clip 复用编辑草稿或读取废弃 RunningHub 工作流的行为。
- 历史画布只在导入时单向归一化，不长期双写新旧字段。

不采用局部补丁方案，因为继续在 DOM 事件中分别维护宽度、时长和选中项会再次产生“显示已变、保存没变”的分叉；也不完全重写，因为现有能力档案和视频执行链已经可复用。

## 三、共享状态契约

### 3.1 工程时间状态

导演台保存以下工程级状态：

- `timeline_zoom`：时间轴显示比例，使用有上下限的数值。
- `timeline_scroll_ms`：当前视口左边界对应的时间。
- `timeline_min_view_ms`：没有 Clip 或删除 Clip 后仍保留的最小可视时长。
- `selected_clip_id`：当前选中 Clip。

时间轴不是固定的 16 秒或所有 Clip 时长之和。可视总长取“最小可视时长、最右 Clip 终点加安全余量、当前滚动视口终点”三者最大值，因此可以持续向右移动和扩展。

### 3.2 Clip 独立状态

每个普通 Clip 独立保存：

- `start_ms` 与 `duration_ms`；
- `input_refs`，并保留素材类型、用途、顺序和稳定素材 ID；
- 提示词；
- 平台、模型、运行模式和该模型的参数草稿；
- 结果版本、当前结果、运行记录与错误状态。

项目素材库是共享索引，Clip 输入是各自独立的引用集合。切换 Clip 只能切换视图，不能把当前 DOM 中的素材清单写入另一个 Clip。

点击“新增 Clip”后立即选中新 Clip。新 Clip 只使用产品默认值，不继承此前选中 Clip 的素材、提示词、平台、模型、运行模式、参数、结果或运行状态。原 Clip 的全部状态保持不变。

连接 Clip 继续与普通 Clip 使用同一条轨道和独立状态，但其锁定时间线输入由覆盖关系自动计算。

## 四、时间轴交互

### 4.1 移动、留白与删除

- 普通 Clip 可以沿时间轴左右移动，开始时间和时长按整秒对齐。
- Clip 之间允许留白；播放头进入留白时预览黑场。
- 删除 Clip 后保留它占用过的空白，不自动压紧右侧 Clip。
- 保存重开后必须恢复所有 Clip 的绝对开始时间，不按数组顺序重新排布。

### 4.2 碰撞规则

- 普通 Clip 向右移动或向右延长并碰到后续普通 Clip 时，把被碰到的 Clip 以及连续受影响的后续普通 Clip 整体向右推，保持各自时长和内部状态不变。
- 普通 Clip 向左移动碰到前一个普通 Clip 时，夹紧到前一个 Clip 的终点，不反向推动此前 Clip。
- Clip 缩短后，之前被推远的后续 Clip 不自动回退，空出的时间保留为间隙。
- 连接 Clip 不推动普通 Clip。它只改变自己的覆盖范围，并重新计算时间线输入；连接 Clip 之间仍不允许发生无法判定优先级的重叠。

因此，8 秒的 Clip 1 紧邻 8 秒的 Clip 2 时，把 Clip 1 延长到 15 秒会把 Clip 2 从第 8 秒推到第 15 秒；把 Clip 1 再缩回 8 秒后，Clip 2 仍从第 15 秒开始。

### 4.3 时长双向同步

- 普通 Clip 左右边缘都可拖动；每次变化按整秒提交。
- 右边缘改变 `duration_ms`；左边缘同时改变 `start_ms` 与 `duration_ms`，右端固定，并遵守左侧碰撞规则。
- 当前模型用离散时长选项时，只能停在支持值；模型使用最小值、最大值和步长时，按档案约束取值。
- 时间轴拖边改变的时长立即同步到右侧参数面板。
- 右侧时长选择或输入改变后，立即更新 Clip 宽度并应用向右推挤规则。
- 切换模型导致当前时长不再支持时，不静默提交旧值；界面说明新约束，并要求用户选择合法时长或采用该模型明确声明的默认值。

### 4.4 缩放、滚动与作用域

- 指针位于当前已选中导演台的时间轴区域时，`Control + 滚轮` 缩放时间比例。
- 缩放以指针指向的时间为锚点，标尺、普通 Clip、连接 Clip、播放头和覆盖范围同步缩放，避免画面跳走。
- 单独滚轮只横向滚动时间轴视口，不缩放整个画布，也不改变 Clip。
- 这些快捷交互只在导演台节点已选中且指针位于导演台时间轴内时生效；离开导演台后，画布原有快捷键和滚轮行为不受影响。
- 时间轴捕获本次交互后阻止画布平移或缩放，不能一次操作同时改变两层视图。

## 五、界面布局

### 5.1 顶部工具栏

顶部工具栏放置工程名、播放、运行当前、批量运行、新增 Clip、新增连接 Clip、下载和导演台快捷键说明。新增按钮不再放进时间轨道。

右上角统一使用“下载 / Download”，不使用“导出 / Export”。下载仍按所有普通 Clip 与连接 Clip 的时间中点排序，生成独立视频文件与追溯清单，不拼接成成片。

快捷键说明使用与画布一致的锚定弹层，但内容只列导演台操作，并明确其生效范围：

- `Control + 滚轮`：缩放时间轴；
- `滚轮`：水平浏览时间轴；
- 拖动 Clip：移动；
- 拖动 Clip 边缘：按秒调整时长。

中英文文案同步维护。

### 5.2 当前 Clip 工作区

时间轴下方使用三列稳定布局：

1. 左列“Clip 素材”：图片、视频、音频和文本按类型分组，并在各组内垂直罗列。这里显示当前 Clip 的独立 `input_refs`，不是项目素材库的副本。
2. 中列“提示词”：完整提示词编辑、`@引用` 和与当前输入相关的状态提示。
3. 右列“生成设置”：平台、模型、运行模式和能力参数。

右侧参数不再压成细小多列网格。一级选择保持清楚的单行项目，动态参数按一项一行排列；选项弹层继续复用视频节点的能力档案、默认状态和提交过滤规则。宽度不足时本列内部滚动，不让参数覆盖提示词或素材。

## 六、个性化导演台适配器

个性化导演台一级来源只有：

- 本地 ComfyUI；
- RunningHub ComfyUI。

本地 ComfyUI 的二级入口选择当前本地配置中可用的工作流。RunningHub ComfyUI 的二级入口只选择 API 设置中已经通过官方 Schema 同步的 RunningHub AI 应用。

RunningHub AI 应用字段复用现有 RunningHub ComfyUI 节点的规范化结果：

- 严格按官方 `nodeInfoList` 顺序；
- 保留显示标签和真实提交值；
- 媒体输入映射到左侧 Clip 素材组；
- 文本、数字、选择、开关等字段映射到右侧参数区；
- 已连接或已拖入的素材按稳定目标键映射，不依赖数组位置；
- 缺少或变化的 Schema 明确阻止运行并写入日志。

废弃的 RunningHub “工作流 ID / 工作流 JSON / 机器规格”入口不进入新导演台。现有历史画布仍可通过兼容入口读取，但 API 设置中将其标记为“已废弃 / Deprecated”，新版导演台不得把它列为候选，也不得用它作为 AI 应用失败后的静默回退。

## 七、连接 Clip 联动

普通 Clip 移动、调整时长或切换当前结果后，所有覆盖它的连接 Clip 立即重新计算：

- 左侧覆盖少于 1 秒取上一个普通 Clip 的尾帧；
- 右侧覆盖少于 1 秒取下一个普通 Clip 的首帧；
- 覆盖至少 1 秒按真实覆盖区间提取相应视频；
- 没有任何有效时间线来源时禁止运行并说明原因。

重新计算只更新可派生的时间线输入和兼容模型候选，不覆盖用户自己的提示词与有效参数草稿。

## 八、保存、迁移与异常处理

- 新状态保存前按稳定 Clip ID 归一化；重开后不压紧、不重新编号状态对象、不共享引用数组。
- 旧 `segments` 首次载入时转换为带绝对时间的 Clip；缺少开始时间的历史数据只在迁移时按原顺序连续排列一次。
- 删除、移动和调整时长都进入同一撤销记录，避免只恢复宽度却没有恢复开始时间。
- 素材拖入、模型切换、时长不合法、AI 应用 Schema 缺失和连接来源失效等错误先写画布日志，再显示可操作提示。
- 保存状态不包含 DOM 节点、像素宽度或临时拖拽对象；显示宽度始终由时间值和缩放比例计算。

## 九、验收标准

### 9.1 时间轴

- 两个 8 秒 Clip 初始连续；删除第一个后，第二个仍停在第 8 秒。
- Clip 1 从 8 秒延长到 15 秒会把 Clip 2 推到第 15 秒；Clip 1 缩回 8 秒后 Clip 2 仍位于第 15 秒。
- 向左移动不能压住前一个普通 Clip；向右移动会推动连续后续 Clip。
- 拖边和参数输入都按当前模型的整秒合法值变化，并双向同步。
- 缩放后指针下时间不漂移；滚轮只横向浏览；离开导演台后两种操作不劫持画布。

### 9.2 Clip 隔离

- Clip 1 加入素材、提示词和参数后，Clip 2 不显示也不提交这些数据。
- 新增 Clip 后立即选中新 Clip，所有内容为空白或产品默认值；原 Clip 数据仍可切回查看。
- 新增 Clip、切换 Clip、保存重开和重渲染都不清空其他 Clip 的素材。

### 9.3 个性化来源

- RunningHub 二级选择只显示已同步 AI 应用，不显示废弃工作流。
- 切换 AI 应用后按官方顺序显示字段，并提交真实字段值。
- 本地 ComfyUI 与 RunningHub AI 应用的选择、草稿和结果在不同 Clip 间隔离。

### 9.4 界面与下载

- 新增两个按钮位于顶部；时间轨道内不再出现新增按钮。
- Clip 素材、提示词、生成设置从左到右清晰分栏，参数逐行可读。
- 右上角及相关提示统一显示“下载 / Download”。
- 下载文件仍按 Clip 时间中点排序并统一命名，不暴露普通或连接类型。
