# 平台适配说明

能力档案描述“模型能做什么”，平台适配器负责“怎么调用”。两者不能互相替代。

## 平台职责

| 平台 | 适配协议 | 档案来源 | 当前维护重点 |
| --- | --- | --- | --- |
| laohu | OpenAI 兼容及专用媒体接口 | 官方 `/v1/models`、已验证历史档案、项目适配器 | 文本、图片、视频、音频的操作模式和字段依赖 |
| RunningHub | RunningHub API、远端应用/工作流字段 | 官方模型注册表、远端字段快照、项目适配器 | 动态输入编号、字段类型、应用和工作流参数 |
| ModelScope | OpenAI 兼容 | 当前项目请求、官方模型资料 | 任意新增模型先进入待确认，不能从名称推断图生图 |
| 火山引擎 | 方舟协议 | 官方 Schema、项目适配器 | 用户添加模型后再建立档案；当前没有默认模型 |

## 统一运行链路

```text
画布连接的素材
→ 推导统一任务语义和输入角色
→ 能力档案筛选产品模型家族
→ 路由到唯一任务变体和真实模型 ID
→ 生成平台无关的标准请求
→ 后端按档案校验输入和参数
→ 平台适配器转换字段、上传和异步任务
→ 统一登记结果和原始追踪信息
```

前端不得把 RunningHub 的 `fieldName`、laohu 的请求字段或平台轮询细节当作通用节点字段。平台变化优先修改适配器和平台档案，节点只消费统一语义。

同一个产品模型可以对应多个平台接口。例如视频模型可分别提供文生、首帧、首尾帧、多参考、编辑和延长变体；用户只选择产品模型家族，系统依据操作模式和输入角色选择真实接口。国内站、国际站、VIP 或低价通道属于部署路由，不能拆成新的画布平台或重复模型家族。

目录接口返回模型名称不代表适配完成。平台目录、能力档案和运行适配器必须分层：目录负责发现，能力档案负责证明，适配器负责转换和执行。静态请求快照通过时只标记 `contract_validated`；只有获得授权并完成真实结果落地验证后，才能标记 `runtime_verified`。

自定义平台使用受 Schema 约束的 Provider Manifest 描述目录、模型家族、任务变体、能力、请求映射和任务协议。Manifest 不允许内嵌任意脚本；AI 根据第三方文档生成的内容只能作为草稿，必须经过 Schema、语义、域名安全和请求快照校验后启用。

## 证据来源

- laohu 人类文档入口：`https://api.lao-hu.com/`
- laohu 鉴权模型目录：`https://api.lao-hu.com/v1/models`
- RunningHub 模型注册表：`https://raw.githubusercontent.com/HM-RunningHub/ComfyUI_RH_OpenAPI/main/models_registry.json`
- 本地用户模型入口：`data/api_providers.json`
- 本地请求实现：`main.py`、`static/js/smart-canvas.js`

2026-09-12 已恢复并核对官方 [llms.txt](https://api.lao-hu.com/docs/llms.txt)。本次补齐 Image G v2.5 三个通道、新文本模型、MiniMax-H3 V2、Suno V6 翻唱/续写/自定义模型、Seedream 5、VOSR2 和 FlashVSR 的档案与协议。MiniMax 保留角色与驱动音频字段；创建请求只发送一次，不确定受理时按 X-Task-Id 查询。Suno 自定义模型接受 6–24 条音频并将 model_id 保存为文本素材。

当前 laohu 完整目录 262 项：259 项具有可运行档案，0 项缺少档案，3 项标记适配器缺口（Hunyuan3D 文生/图生 3D、Kling 唇形 TTS）。3D 文件尚不属于画布四种素材类型，不能用视频或图片假装已经支持；Kling 唇形 TTS 仍缺少完整请求适配。这些项不会被标成可以生成。可运行档案是无付费协议验证结论，不等同于本账号已实付生成成功。

用户启用模型列表保持独立：升级档案不自动加回用户删除的模型。要使用新模型，在 API 设置主动拉取并勾选，再到画布或 Agent 默认设置中选择。
