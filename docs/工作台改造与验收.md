# 创意工作台改造与验收

2026-09-19。本轮依据《精简画布适配模型》最后一轮约定及随后真实页面反馈实施。产品标识为 `laohu-creative-studio`，最新中文显示名为“老胡画梦枋”。本文区分已实现、已验证与剩余边界，不把计划写成结果。

## 视觉与连接整理：本轮验收范围

依据后续讨论 `6aae7e96-0374-83ed-97a3-56602ccba1db` 的最后修正：保留功能和管理方式，整理连接设置、模型选择与视觉。早期“将工作流混入普通模型”“项目模型快照与模块默认分开”“整体搬目录”的建议不属于本轮目标。

实施选择：采用在原页面、原配置与原调用上整理的保守改造。新增第二套设置存储会造成配置分叉，全面替换工作台会改变用户熟悉的管理流程，两者均不采用。旧项目、节点 ID、连线、素材和用户启用模型清单保留。

验收清单：
- 左侧画布、Hypit、素材库；设置集中连接、主题和语言。
- 连接按平台、站点应用、本地工作流、CLI 整理；画布模型多选与 Hypit 能力单选职责分开。左侧菜单常驻，画布模型在 Hypit 前，取消重复切换和返回入口。
- 所有设置自动保存；文本防抖，选择立即，保存失败保留草稿。RunningHub 左 AI、右 CN 独立开关与凭据；双关保留配置，历史任务仍按原站查询。
- 页面只保留配置任务需要的信息：去掉内部环境变量、固定地址展示和重复能力介绍，保留获取凭据、保存状态及可行动错误。
- 画布模型入口合并，参数一行一字段、短值完整；AI 应用及本地 ComfyUI 仍为独立节点。
- Hypit 全部项目后续执行使用统一模块模型；旧任务仍按提交时请求运行，重复请求不重新收费。
- 暖色浅主题、协调深主题和原生 Studio 内部主题；素材颜色不变。
- 真实页面和回归通过后记录具体结果，不能以 CSS 文件存在代替视觉验收。

## 产品与数据约定

- 左侧菜单区分画布、Hypit；模块内采用统一项目列表，不重复展示工作台介绍和模块切换。项目不再按分组管理；保留画布内部节点分组。
- 新建时先命名，点击“创建项目”后只创建记录、更新列表；点击卡片“打开项目”才打开新标签。取消不创建记录和空标签。标签标题固定为模块名。
- 旧画布直接作为项目读取，保留原 ID、名称、节点、连线和素材，不复制第二套作品。接口读取失败明确报错，不能显示空库。
- “获取创作技能”只在 Hypit 提供，说明如何在用户自己的 Agent 环境获取官方 Skill；“接入当前项目”提供当前项目、数据、参数、执行和查询说明。软件不打包创作 Skill，不替用户另装独立 Studio。
- 同项目可以多开可编辑页，也可以关闭所有页面。项目及生成任务由服务端持久保存；连接和保存不会自动生成。

## 存储与依赖

工程：`workflows/hypit/<项目ID>/`；结果：`assets/output/hypit/<项目ID>/`；配置、任务和绑定：`data/`；运行环境：`runtime/hypit/`；可重建缓存：`cache/hypit/`；迁移备份：`backups/`。输入素材继续使用现有素材服务。删除项目不删除生成素材。

Hypit 基线：上游提交 `a45224c32da6e25bd641e403920ab17d48838417`，原生包 0.2.7。工程使用 `hypit.results.json` 指定结果目录，`HYPIT_STATE_HOME` 指定主机状态。原生 Comments/FEEDBACK 与制作语义保持原生。受管桥接包以真实文件复制，不借助符号链接。

只保留已有业务适配器作为实际请求入口，不增加第二套 Key、请求客户端或假参数。界面样式统一不意味着不同模型的参数相同。用户删除的模型不得被候选目录自动加回。

## 验证记录与边界

上一轮 2026-09-19 主分支发布时，本机固定回归共 785 项，784 项通过，原生合约测试默认跳过 1 项；该项已单独执行通过。命令：`TMPDIR="$PWD/cache/astra-luna" .venv/bin/python tools/check_regression.py`。原生合约测试单独执行：`STUDIO_NATIVE_HYPIT_TESTS=1 .venv/bin/python -m unittest tests.test_hypit_native_contract -v`，要求先具备固定版本受管运行环境。普通回归不下载该依赖，因此该测试默认跳过。

真实验证包括：旧画布 58 个节点仍保留；命名后创建并打开；Hypit/画布入口区别；双标签同步及稳定编号；原生 1 秒视频渲染；原生 Build 对本地假模型生成图片，并校验结果封装与一次提交。验证没有调用收费模型接口。测试项目和生成媒体单独清理，旧用户画布不重建。

以下不作为已完成验证：

- Windows 未实机运行。路径、解释器、子进程采用跨平台写法，安装不依赖 POSIX 链接；正式发布仍须 Mac/Windows × Python 3.10/3.14 回归矩阵以及真实浏览器/CLI 验证。
- 未使用用户 Key 做付费生成，也未连接真实 RunningHub 或本地 ComfyUI 执行收费/生产工作流；当前验证是契约、假回调和原生引擎的组合。
- Hypit 原生桥接当前为明确模型能力槽；任意 AI 应用/ComfyUI 工作流尚不能直接当作这些模型槽选择。画布后台已支持它们，Hypit 侧若扩展，需要工作流输入/输出 Schema 映射，不能仅按媒体类型猜测兼容。
- 中断的本地操作显示可恢复并保留原任务标识，不自动重新付费提交；不承诺上游平台没有取消接口时能远程撤销。
- Hypit 包含附加许可条件，商业分发/第三方托管受限制。当前为用户显式安装、本地适配；公开商业捆绑前需单独确认授权。
- 2026-09-19 按用户要求提交并合并主分支，产品版本同步为 2026.09.19。本次为源码更新，不生成正式 R2 安装包；底层进一步统一与未验证边界不因此变为已完成。

后续音乐、歌词、文章仅沿用项目、接入、模型任务和素材接口，不在本轮开发专业界面。Hypit 上游更新须显式核验官方变更、桥接合约和许可，再更新固定版本，不能让 Agent 准备 Skill 时顺带覆盖工作台程序。

## 插件执行记录

按 Astra + Luna Command Center 分工完成审计、项目页、模型选择、无页面执行、Hypit 模型桥接、多页同步及应用工作流执行。Astra 对结果逐项复核，并修正原生封装、任务恢复、参数继承和真实 UI 问题。包哈希、结果与审核记录位于 `cache/astra-luna/`，不进入发布包。原插件的 macOS CPU 时间解析问题只在任务缓存副本修正，未修改已安装插件。


### Hypit 打开入口修复

项目公开 URL 曾错误指向 `hypit-list.html?id=…`，导致创建后或点击打开再次进入列表，与 Agent 是否连接无关。现统一返回 `hypit.html?id=…`，旧列表地址带 ID 时单向跳转到相同项目。新增回归覆盖创建、列表、读取三条返回路径；真实浏览器验证旧地址进入项目页。尚无 `.svrun` 的新工程显示空状态，原生预览等待实际制作内容；项目页面本身不要求 Agent 在线。


### 项目管理与作品页分工

创建后留在管理页。管理页提供常驻步骤指引、可阅读后复制的 Agent 接入指令、Hypit 技能准备、项目模型设置及缺少时的预览组件安装；指引明确说明要把内容粘贴到外部 Agent。画布无需额外技能准备。画布中原 Agent 接入按钮改为节点默认设置，只保留模型参数编辑；接入说明归项目卡片。Hypit 作品页不再重复这些入口，发现可用制作方案后自动打开原生 Studio，空工程只有简洁空状态和返回管理入口。


接入与技能准备统一使用短指令。`/api/studio/projects/{id}/connection.md` 提供带实际项目接口地址的独立 Markdown 对接文档，`/api/studio/modules/{module}/preparation.md` 提供技能准备文档；复制框只包含身份、文档链接和读取要求。中英文、画布/Hypit 均有 HTTP 回归覆盖。
